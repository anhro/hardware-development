## Завдання

- [x] ✅ **1. Ширина провідників для 4 А × 2.** IPC-2221, зовнішній шар 1 oz, ΔT ≈ 20 °C →
  **3.5 мм** (при 8 А ΔT ≈ 19.7 °C, при 4 А ≈ 4.1 °C). Внутрішні шари 0.5 oz для силового струму
  не підходять (18 мм). Via 0.8/0.4 мм ≈ 2.4 А, для 8 А — не менше 4.
- [x] ✅ **2. Клас мереж `HIGH_CURRENT`.** Шаблони `+12_IN`, `+12_FUSED`, `+12M`,
  `/Inverter/PWR.S*`: доріжка 3.5 мм, зазор 0.2 мм, via 0.8/0.4 мм, priority 0.
  Колишній клас `Power` перейменовано. Мережа після F1 отримала power-мітку `+12_FUSED`.
- [x] ✅ **3. Правило `high_current`.** У `motor-drive-controller.kicad_dru`:
  - `high_current` — мінімум 3.5 мм, зазор 0.2 мм, via ≥ 0.8/0.4 мм;
  - `high_current_neckdown_12m` і `high_current_neckdown_taps` — звуження до 0.5 мм лише для
    названих мереж біля названих компонентів;
  - `high_current_zone_smd` — суцільне підключення силових SMD-падів до полігонів.

  Перевірено на копії плати: без винятків DRC видає 33 помилки `track_width`, усі їх покривають
  винятки. Доріжки `+12_FUSED` 2.7 мм нові винятки не пропускають — їх розширено до 3.5 мм.
- [x] ✅ **4. Трасування листа Inverter від входу живлення, без GND.** XT1 → F1 → VD1/VD3/VD2 →
  `+12M` → ключі: усе на F.Cu, доріжки 3.5 мм і полігони, без via у силовому колі.
  GND не трасовано.
- [x] ✅ **5а. J5 і силові ключі з'єднані полігонами.** Полігони `PWR.SHA/B/C` з'єднують контакти
  J5 з витоками верхніх і стоками нижніх ключів.
- [x] ✅ **5б. Силові ключі з'єднані між собою полігонами.** `PWR.SHx` — верхній ↔ нижній ключ
  кожної фази; `+12M` — стоки верхніх ключів, конденсатори C25/C29/C32, C38, C24.
- [x] ✅ **5в. Kelvin-підключення шунтів (4-wire).** NetTie NT1–NT6 на внутрішніх краях падів
  R16/R19/R22, окремі мережі `SH_Hx`/`SH_Lx` у класі `KELVIN_LINE` (0.3 мм). Пари йдуть разом до
  RC-фільтрів R13–R21/C27, C30, C33. Зазор NetTie ↔ пад шунта 0.31–0.37 мм.
- [x] ✅ **5г. PWM не паралельно аналоговим лініям.** `tools/check-parallel.py`: паралельних
  ділянок із зазором < 1 мм — **0**; найближча — `GATE.GLC` ↔ `SH_LA`, 2.5 мм із зазором 1.0 мм
  (> 3 × 0.3 мм). Ділянку `GATE.GLB` ↔ `SH_HA` (2.5 мм / 0.2 мм) з першої версії виправлено.
  PWM від MCU (`DRV.INHx/INLx`) ще не розведено.
